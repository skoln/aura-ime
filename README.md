# Aura-ime（光环输入法）

> 即时接话 · 灵动润色 · 本地优先

Aura-ime 是一款 AI 驱动的智能输入法，专注于帮你更好地表达。

它不替你做决定，而是在你需要的时候，给出更合适的说法。


## 项目状态

**积极开发中 · 早期架构搭建阶段**

- 当前进度：输入法框架 + 混合推理层设计
- 下一步：接入本地小模型（Qwen 0.6B）+ 可选云端 API
- 目标：在离线流畅与云端智能之间找到最佳平衡点

## 核心功能（规划中）

| 功能 | 说明 |
|------|------|
| 接话模式 | 根据聊天上下文，一键生成 3 种语气风格的候选回复 |
| 润色模式 | 选中已有文字，AI 调整表达方式，保留原意，让表达更精准 |


## 混合推理策略

Aura-ime 采用「本地优先 · 云端可选」的双轨架构：

| 场景 | 使用方式 | 特点 |
|------|----------|------|
| 日常接话 / 润色 | 本地模型（Qwen 0.6B） | 响应 < 300ms，离线可用，隐私安全 |
| 复杂语境 / 长句重写 | 可选云端 API（如 DeepSeek / OpenAI） | 需用户自行配置 API Key，能力更强 |
| 无网络环境 | 纯本地降级运行 | 可用，但模型能力较弱 |

所有 AI 调用均通过统一抽象层，本地与云端切换对用户无感知。


## 未来路线图

- 更丝滑的 UI：打磨动画与触摸反馈，手感对标主流输入法
- 智能路由：自动判断场景，简单任务走本地，复杂任务走云端
- 个性化记忆：本地微调小模型，学习你的语气和常用表达
- 多语言支持：中英混输 + 方言风格
- 插件化润色滤镜：开放接口，支持用户自定义风格
