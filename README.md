# Aura-ime（光环输入法）

> 接话 · 润色 · 本地优先

aura-ime 是一款 AI 驱动的智能输入法，专注于帮你更好地表达。

它不替你做决定，而是在你需要的时候，给出更合适的说法。

## 核心功能（规划）

- 接话模式：根据聊天上下文，一键生成 3 种语气的候选回复
- 润色模式：选中文字，AI 调整表达方式，不动原意


## 混合推理策略

aura-ime 采用本地优先、云端可选的双轨架构：

| 场景 | 使用方式 | 说明 |
|------|----------|------|
| 日常接话/润色 | 本地模型（Qwen 0.6B） | 响应 < 300ms，离线可用，保护隐私 |
| 复杂语境/长句重写 | 可选云端 API（如 DeepSeek / OpenAI） | 需用户自行配置 API Key |
| 无网络环境 | 纯本地降级 | 可用，模型能力较弱 |

所有 AI 调用经过统一抽象层，本地与云端切换对用户无感知。


## 未来路线图

- 更丝滑的 UI：打磨动画与触摸反馈，手感对标主流输入法
- 智能路由：自动判断场景，简单任务走本地，复杂任务走云端
- 个性化记忆：本地微调小模型，学习你的语气和常用表达
- 多语言支持：中英混输 + 方言风格
- 插件化润色滤镜：开放接口，支持自定义风格
