## 项目简介

光环输入法（Aura-IME）是一款专为**聊天场景**设计的智能输入工具，通过 AI 技术实时提供**接话建议**与**文字润色**，帮助你更轻松、更得体地应对各类对话。无论是社交闲聊、工作沟通，还是内容创作，光环输入法都能成为你的“隐形笔友”。

我们坚持 **本地优先** 的推理策略，所有敏感数据默认在设备端处理，最大程度保障你的隐私安全；同时支持**云端扩展**，当遇到复杂需求时可调用更强大的模型，兼顾灵活性与可控性。

---

## 核心特性

- 聊天接话建议  
  基于上下文语义，智能预测你可能想说的下一句话，提供多个风格（幽默、正式、亲切等）的回复选项，告别“词穷”时刻。

- 文字润色  
  对已输入的内容进行语法纠错、语气调整、措辞优化，让表达更流畅、更得体，同时保留个人风格。

- 本地优先，隐私安全  
  核心推理引擎运行在本地，数据不离设备；可选云端模型用于高难度任务，且传输全程加密，用户可随时关闭云端功能。

- 轻量 & 跨平台  
  采用高效推理框架，资源占用低，支持 Windows / macOS / Linux 主流桌面环境，后续将覆盖移动端。

- 持续进化  
  项目处于活跃开发中，未来将加入自定义词库、场景识别、多语言支持等更多实用功能。

## 适用场景

- 社交聊天：微信、QQ、Telegram 等即时通讯中，快速生成恰当回复。
- 工作邮件 / 商务沟通：润色文字，使表达更专业、清晰。
- 内容创作：辅助撰写文案、推文，激发灵感。
- 外语交流：提供翻译和地道表达建议（规划中）。

## 使用方式

- 输入法将以系统级 IME（输入法框架）或独立应用形式运行。
- 开启后，在任意文本框中输入内容，AI 建议将实时呈现在候选窗口中。
- 可通过快捷键或鼠标点击选择建议、触发润色。

---

## 技术架构

- 本地推理引擎：基于 ONNX Runtime / llama.cpp 等轻量推理库，支持 CPU / GPU 加速。
- 模型选型：预置专为对话场景微调的小型语言模型（< 3B 参数），兼顾性能与效果。
- 云端扩展：可选接入 AI API 或自部署模型服务，用于高复杂度任务。
- 隐私保护：所有本地数据不落盘，云端请求采用匿名化处理，用户可完全禁用网络功能。
